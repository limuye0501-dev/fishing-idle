# 漂流瓶史料来源 / Bottle history sources

游戏里的漂流瓶全部是**真实史料的简短摘录**，不含虚构引文。所有来源都在公有领域：作者去世超过 70 年，或作品 1930 年前出版。
- 英文原文逐字摘录（`…` 表示省略）；中文为我们的忠实翻译。
- 中文古籍（鉴真、郑和）保留原文，英文为我们的翻译。
- Bradford 原文为 17 世纪拼写（如 y^e = the），游戏内改成了现代拼写。
- 游戏内每个瓶子都标注“真实摘录 · 出处”。目前没有任何戏剧化改编条目；以后如果加，必须标“据史实改编”。
- 背景注释只写有据可查的事实。涉及遇难的条目使用克制、尊重的语气。
