2つの釣り方

• 手動：ソナーで魚群を探し、タイミングよく網を投げ、テンションを保って巻き上げ。失敗しても魚は逃げず、サイズが少し小さくなるだけ。アシストモードあり

• 東シナ海 → 大西洋 → 太平洋 → インド洋 → 北極海 → 南極海
