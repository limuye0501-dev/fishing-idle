# App Store 元数据 · 简体中文（草稿，v2）

**App 名称（≤30）**：船长别回来

**副标题（≤30）**：小船长的治愈系远洋渔船

**推广文本（≤170）**：
给你的渔船起个名字，和小船长一起出海吧！从东海近海一路开到南大洋，39 种真实鱼类等你捕获。挂机离线也在打鱼，想动手时还能亲自撒网。一次买断，无广告、无追踪。

**关键词（≤100 字节，逗号分隔、不加空格）**：
放置,挂机,钓鱼,捕鱼,渔船,船长,海洋,图鉴,水族箱,休闲,治愈,离线,航海

**描述**：
你有一艘属于自己的大拖网渔船，船长是个戴白色船长帽的小男孩。船一直漂在海上：日出日落、风来雨去，都在慢慢地捕鱼。回不回港，你说了算。

【两种玩法】
• 挂机：渔船自动作业，离开游戏时也在打鱼，回来时有一张离线收获卡
• 亲手捕鱼：声呐找鱼群 → 看准时机撒网 → 控制张力收网，手感越好鱼越大越稀有

【六大海域】
• 东海近海 → 大西洋 → 太平洋 → 印度洋 → 北冰洋 → 南大洋，逐片解锁
• 加固船体才能闯进浮冰海域，捕到小头睡鲨、南极大磷虾和莫氏犬牙南极鱼
• 小地图实时显示你的船开到了哪里

【航海经营】
• 燃油、鱼舱、新鲜度：回港全价卖鱼，或叫收购船来海上收鱼
• 升级引擎、鱼舱、声呐、绞机、冰柜和船体，学习船长技能
• 天气、昼夜和四季都会改变能捕到什么
• 任务、纪录大鱼、图鉴和私人鱼缸

【良心承诺】
• 一次买断解锁完整版，宝石只能在游戏里获得，永不出售
• 无广告、无第三方统计、无追踪，不收集任何个人信息
• 支持中文与英文

3D 场景由代码原创生成，世界地图来自 Natural Earth（公有领域），鱼类照片来自 Wikimedia Commons（作者与许可见游戏内图鉴）。
