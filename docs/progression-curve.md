# 长期节奏 / Progression curve (v9)

测算来自 `V9Tests.testIdlePacingDoesNotCapOutIn50h`（满配船：全部部件 6 级、渔具 5 级、技能 5 级、印度洋、晴天，每 30 分钟叫收购船，属于理想化的高强度玩家）：

| 指标 | 数值 |
|---|---|
| 满配船挂机收入 | ≈ 70,000 金币/小时（≈ 350 万 / 50 小时） |
| 长期金币去处总额（鱼缸装饰 10 件 + 船体涂装 8 种） | 27,247,000 |
| 满配后买完全部去处所需挂机时长 | ≈ 390 小时 |

再加上达到满配之前的部件/渔具/鱼缸升级（前 30–60 小时的主要支出），普通玩家（每天回来 2–3 次、离线 12 小时上限、收购船 75% 价格）实际收入约为上表的 1/3–1/2，钱花完需要约 **800–1,200 小时** 的挂机时间。

不靠金币的长期目标：39 种鱼 × 闪光变种（0.4% / 条，主动捕鱼 ×3，雾雨天 ×1.3–1.5）、每种鱼的纪录体型（可生成分享卡）、12 张漂流瓶纸条、船猫爱心（每天 1 次）。

各项去处价格呈约 ×2.4 的几何增长（装饰 2k → 5.5M；涂装 8k → 12M），因此无论处于哪个阶段，总有一件“再挂一会儿就能买”的东西。
每件鱼缸装饰让卖鱼收入 +2%（最多 +20%），所以装饰不只是好看，买了也有回报，但不会让收入暴涨。
